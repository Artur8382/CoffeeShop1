# Internship Dynamics & Azure / Full Stack – 2026

## Project Overview

The project focuses on object-oriented design, database modeling, and business logic implementation using C# and .NET.

It is divided into two independent domains:

- **Problem 1 – Coffee Shop Management System**
- **Problem 2 – SieMarket E-Commerce Order System**

Both problems demonstrate clean architecture principles, proper modeling, and real-world backend logic.

---

## Problem 1 – Coffee Shop Management System

Sarah owns a growing coffee shop chain and wants to digitize operations. The system must handle:

### Beverage Management
- Multiple beverage types (Espresso, Latte, Cappuccino)
- Multiple sizes (Small, Medium, Large)

### Customization
- Customizable extras (extra shot, vanilla syrup, caramel syrup, whipped cream)

### Loyalty Program
- Loyalty program (Regular & Gold members)

### Order Management
- Order tracking with baristas
- Price calculation and timestamps

---

## Problem 2 – SieMarket Order System

### Business Scenario

SieMarket is an online electronics store processing hundreds of daily orders across Europe.

### Order Structure

Each order:
- Belongs to a customer
- Contains one or more items
- Stores product name, quantity, and unit price at purchase time

### Discount Rule

If order total exceeds 500€, a 10% discount is applied.
